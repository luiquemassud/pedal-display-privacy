Pedal Display
Política de privacidade

Beta pessoal 0.3.0 · Atualizada em 30 de outubro de 2026

O Pedal Display é um campo Connect IQ para Forerunner 955 e um painel separado para iPhone. O relógio grava a atividade; o painel exibe os dados recebidos. Esta política descreve o código da beta 0.3.0.

Dados tratados e finalidade

Durante a atividade Bike, o campo acessa velocidade, frequência cardíaca, potência, cadência, distância, tempo ativo, altitude, subida, posição GPS, rumo, qualidade GPS e eventos de volta disponíveis no relógio. Esses dados são enviados por Bluetooth ao iPhone aprovado para exibir o pedal e seguir o percurso. Dados indisponíveis não são inventados.

Transmissão e primeiro vínculo

As características Bluetooth exigem criptografia. No primeiro vínculo, compare o código no relógio e no painel, aprove no iPhone e só depois aperte START no relógio. Os dois aplicativos lembram a identidade do dispositivo aprovado e não trocam silenciosamente para outro aparelho após falha. Essa comparação não é atestação criptográfica da identidade do aplicativo.

Armazenamento

O painel mantém as métricas, posição e histórico recente de voltas em memória durante seu uso; não cria um arquivo de atividade. A identidade Bluetooth aprovada fica salva localmente em cada dispositivo. Um GPX escolhido pelo usuário é copiado para armazenamento local do iPhone, com proteção de arquivo e exclusão do backup. O GPX pode conter localização precisa. Não o compartilhe se não desejar divulgar o trajeto.

Servidores e terceiros

O código desta beta não envia dados de atividade, GPX ou identificadores para servidores do desenvolvedor, não contém publicidade ou analytics e não solicita conta, senha ou token. O treino continua sujeito à gravação/sincronização normal do sistema Garmin e às escolhas do usuário no Garmin Connect. O provedor escolhido no app Arquivos para importar um GPX segue sua própria política.

A hospedagem desta página pode processar dados técnicos da visita, como endereço IP e informações de requisição, conforme a política de seu provedor. Esta página não inclui formulários, cookies de aplicação, analytics ou scripts de rastreamento.

Controle e remoção

Fechar o painel interrompe seu anúncio Bluetooth. Encerrar a atividade ou remover o campo interrompe o envio pelo relógio. Para remover identidades, use “Vincular outro relógio” no painel e “Esquecer iPhone do painel” nas configurações Connect IQ do campo. Isso não remove automaticamente os vínculos Bluetooth do sistema. Desinstalar o painel remove os dados locais do aplicativo, incluindo o GPX importado; arquivos originais no Arquivos continuam sob controle do usuário. Atividades gravadas pelo Garmin são gerenciadas no relógio/Garmin Connect.

Contato e alterações

Para dúvidas, use o contato do desenvolvedor exibido na listagem do Pedal Display no Connect IQ. Mudanças no tratamento de dados exigirão atualização desta política e da versão do aplicativo. A beta ainda depende de validação física de Bluetooth e reconexão.

Pedal Display
Privacy policy

Personal beta 0.3.0 · Updated October 30, 2026

Pedal Display consists of a Connect IQ data field for Forerunner 955 and a separate iPhone display. The watch records the activity; the phone displays received data. This policy describes the beta 0.3.0 code.

Data and purpose

During Bike activity, the field accesses available speed, heart rate, power, cadence, distance, active time, altitude, ascent, GPS position, heading, GPS quality and lap events. It sends them over Bluetooth to the approved iPhone to display the ride and follow an imported route. Missing measurements are not fabricated.

Connection

Bluetooth characteristics require encryption. For the initial link, compare the code on both devices, approve it on the iPhone and then press START on the watch. Both apps remember the approved peer and do not silently select an unknown replacement after failure. Code comparison is not cryptographic app attestation.

Local storage

The phone keeps ride metrics, position and recent lap history in memory while used; it does not create an activity recording. Approved Bluetooth identities are stored locally on each device. An imported GPX is copied into local protected iPhone storage and excluded from backup. GPX files can contain precise location.

Servers and third parties

This beta code does not upload ride data, GPX files or identifiers to developer servers, includes no advertising or analytics, and requests no accounts, passwords or tokens. Normal Garmin recording and synchronization remain subject to Garmin services and user choices. A file provider selected to import GPX follows its own policy.

The hosting provider of this policy page may process technical visit information such as IP addresses and request information under its own policy. This page includes no forms, application cookies, analytics or tracking scripts.

Control and deletion

Closing the display stops its Bluetooth advertising. Ending the activity or removing the field stops watch transmission. Remove saved identities using the phone’s replace-watch action and the field’s forget-display setting in Connect IQ. This does not automatically remove system Bluetooth bonds. Uninstalling the phone app removes its local data, including the imported GPX copy; original files in Files remain under user control. Manage Garmin-recorded activities on the watch or Garmin Connect.

Contact and changes

Use the developer contact shown in the Pedal Display Connect IQ listing. Any change to data handling requires an updated policy and application version. Physical Bluetooth interoperability and reconnection are still being validated.
